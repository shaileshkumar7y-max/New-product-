# Image asset notes

The site uses:

- 11 existing WebP masters from the current repository root (`../*.webp`). These are reused without replacement.
- 9 new focused WebP crops in this folder, derived from saved campaign artwork for product/detail presentation.

The old `sepia-couples-moodboard.webp` root image is intentionally not displayed in the public gallery because it contains nudity; the public ART ATELIER uses the clothed fashion/runway and romantic poster assets instead.

The 9 local crops are not new original photography. New original campaign/model photographs remain a separate asset-generation task.
