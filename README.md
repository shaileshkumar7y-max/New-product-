## No backend / no paid APIs
All scores, votes, player nickname, wheels, nominations, settings and confession notes stay in this browser's localStorage. They do not sync across devices or users. No login, online multiplayer, live stream, payment, matchmaking, remote feedback or photo upload is connected.

## Existing images reused (do not delete or move)
The gallery uses 17 root-level WebP images and the show / runway UI uses 2 existing posters plus the existing placeholder image. The full 20-file dependency list is in `ROOT-ASSET-DEPENDENCIES.txt`. All 20 filenames were checked against the repository's current `main` tree before packaging. This ZIP intentionally does **not** duplicate any root WebP files.

## Upload on Android
1. Download and extract `big-boss-ke-randiya-v2.zip`.
2. Upload the **`big-boss-v2/` folder** into the root of `shaileshkumar7y-max/New-product-`.
3. Keep `big-boss-v2/assets/` and `big-boss-v2/tests/` intact.
4. Do not replace, delete or move any existing root image files.
5. Commit to `main` and wait for GitHub Pages deployment.
6. Open `https://shaileshkumar7y-max.github.io/New-product-/big-boss-v2/`.
